# 天枢无人机关节控制网站

在项目目录运行：

```powershell
npm run dev
```

然后在浏览器打开终端显示的本地地址（通常是 `http://localhost:5173`）。

## 操作

- `[` / `]`：切换当前关节；也可用 `↑` / `↓`。
- `←` / `→`：让当前关节反向 / 正向微动。
- `R`：旋翼联动转动。
- `0`：所有关节复位。
- 右侧控制卡：可点击关节、拖动滑块，或点击 `−` / `＋`。

## 模型资源

原始 URDF 和 STL 网格的副本位于 `public/robot/`，网站通过 `urdf-loader` 加载。关节限位直接从 URDF 读取；连续关节显示为 ±180° 控制范围。
